HAL
Constructeur de requêtes API
1
Dans quel périmètre ?
Définit les bornes fixes de votre recherche : une collection, une structure, un type de document… Équivaut au fq= dans l'URL.
Aucun filtre — la requête portera sur toute la base HAL. Cliquez sur « Ajouter un filtre » pour restreindre le périmètre.
2
Qu'est-ce qu'on cherche ?
Critères de recherche textuelle dans le périmètre défini. Laissez désactivé pour récupérer tous les documents. Équivaut au q= dans l'URL.
q=* Tous les documents du périmètre seront retournés.
3
Qu'est-ce qu'on affiche ?
Choisissez les champs retournés, le nombre de résultats, le tri et les facettes.
Facettes
ID
Récupérer un document par identifiant
Retourne toutes les métadonnées d'un document précis. Génère q=docid:XXX&fl=*
Entrez le docid numérique du document HAL. L'URL générée retournera toutes les métadonnées disponibles (fl=*).
